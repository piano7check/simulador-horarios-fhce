# Simulador de Horarios FHCE

Aplicación Vue 3 + Vuetify para planificar horarios de clases.

## Requisitos previos

- [Node.js](https://nodejs.org/) v18+
- [pnpm](https://pnpm.io/)

## Instalación

```sh
pnpm install
```

## Desarrollo

```sh
pnpm dev
```

## Build de producción

```sh
pnpm build
```
